# Necronomicon Horror (expanded) — Implementation Plan

## Goal
Evil Dead / Necronomicon pages → Wormhole horror, all procedural (zero image assets,
~700KB bundle). Three deliverables per user request:
1. **10 lore phrases** baked into `story/script.ts` (not 4–5).
2. **Horror prop set** built from `three` primitives + canvas textures, mapped to the
   reference images (flesh-book, deadite heads, skull piles, ritual daggers, dead trees,
   reaching arms, eye-stalks, winged idol, chains, flesh growth).
3. **Silent Hill survival-horror shader pass** on `PostFX.ts` (desat grade, rust
   "otherworld" overlay, heavy grain, flicker, darkness press) + SH fog/light tuning.

- Verify: `npx tsc --noEmit`, `npx vitest run tests/unit`, `npm run build` + size.

## Phase 5 — Silent Hill shader pass (`src/render/PostFX.ts`)
Current FRAG verified: tear → CA → grain → vignette; uniforms
`uScene/uTime/uGrain/uGlitch/uTension/uDepth/uResolution`. Add:
- `uSigil` (blood edge-pulse ring + sparse flicker — the necronomicon flash).
- `uRot` 0..1 otherworld shift (driven by `depth × tension`, see Game wiring).
- **SH color grade**: desaturate toward gray-green (`luma` mix ~0.45 × uRot/depth),
  cold shadows, **preserve reds** (scale R less) so blood/sigils pop.
- **Rust overlay**: 2–3 octave hash value-noise blotches in-shader, rust `#4a2418` /
  dried-blood tint, masked to frame edges + `uRot`, slow crawl with `uTime`.
- **Heavy grain**: coarser SH grain cell (quantized UV hash) with base raised and
  tension-scaled; **luminance flicker** (slow ±0.02 + fluorescent buzz at high tension).
- **Darkness press**: deeper vignette + faint fog-gray lifted blacks.
- Keep tears/CA (scale CA slightly with `uRot`); low-quality skip unchanged.
- `Game.ts` render: decay `sigil`, floor `sigil ≥ depth×tension×0.25`;
  `rot = clamp(depth×0.6 + tension×0.4)`; public `flashSigil(v)`; `scripts.ts`
  `sigilFlash` (spike 0.4 + flash 0.9) hooked to `c12 seam-hall` + `c05 ledge`.
- `DepthDread.ts`: optionally raise `fogBoostForDepth` 0.02→0.03 and extend
  `lightDimForDepth` floor (test only asserts monotonic — safe); flip select deep
  lights to `flicker:'dying'` in c09/c10/c12 data.
- Verify: `?chamber=c09/c12` mood reads SH (gray-green, rust edges, heavy grain);
  panels/portals/puzzles still readable (sight-check each puzzle chamber);
  `?quality=low` path unaffected.

## Scope cuts
No fullscreen reading UI; no animated 3D monsters (props static + sway only);
**no flashlight** (would need light-rig + balance rework — future); no new sounds
(unless trivial `sfx` reuse); no collidable props; no deps; no 512 decals.

## Verification (every phase)
`npx tsc --noEmit` → `npx vitest run tests/unit` → `npm run build` (≈700KB) →
`vite dev` per-chamber visual + readability sight-check → `?e2e=1` smoke.
Order 1→6; each phase independently shippable.
